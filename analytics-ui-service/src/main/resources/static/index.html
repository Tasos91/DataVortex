Μέσος όρος ανά χρονικό κουβά. Τα πεδία με πολύ διαφορετικές μονάδες κανονικοποιούνται για να φαίνονται μαζί.

—

    Ομαδοποίηση

    —

    Ομαδοποιούνται χρονικά παράθυρα, όχι μεμονωμένες εγγραφές: κάθε σημείο είναι ένας κουβάς. Γι' αυτό μένει γρήγορο όσο κι αν μεγαλώσουν τα δεδομένα — αλλά δεν ξεχωρίζει πληθυσμούς που εναλλάσσονται μέσα στον ίδιο κουβά.

    Τα καθεστώτα που βρέθηκαν

    Κέντρο κάθε ομάδας σε πραγματικές μονάδες — όχι κλιμακωμένες, για να λέει κάτι.
